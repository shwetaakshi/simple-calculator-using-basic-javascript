 🧮 Simple Calculator

A beautiful, responsive web-based calculator built with vanilla JavaScript, HTML, and CSS. Features a modern gradient design with smooth animations and intuitive user interface.

✨ Features

- **Four Operations**: Add, Subtract, Multiply, and Divide
- **Modern UI Design**: Gradient backgrounds and smooth animations
- **Responsive Layout**: Works seamlessly on desktop, tablet, and mobile devices
- **Interactive Buttons**: Hover and click effects for better user experience
- **Clean Display**: Clear display of numbers and calculation results
- **Vanilla JavaScript**: No dependencies, lightweight and fast

 🎨 Design Highlights

- Beautiful gradient color scheme with purple, pink, cyan, and orange accents
- Color-coded operation buttons for easy identification
- Smooth button animations on hover and click
- Professional card-based layout with shadow effects
- Mobile-friendly responsive design

 🚀 Getting Started

 Prerequisites
- Any modern web browser (Chrome, Firefox, Safari, Edge, etc.)

 Installation

1. Clone the repository:
```bash
git clone https://github.com/shwetaakshi/simple-calculator-using-basic-javascript.git
cd simple-calculator
```

2. Open the project:
Simply open `index.html` in your web browser or use a local server:
```bash
# Using Python 3
python -m http.server 8000

# Using Python 2
python -m SimpleHTTPServer 8000

# Using Node.js (if you have http-server installed)
http-server
```

3. Navigate to `http://localhost:8000` in your browser

 💻 How to Use

1. The calculator displays two input fields for your numbers
2. Click the operation button you want to perform:
   - **Add** (Purple) - Adds two numbers
   - **Subtract** (Pink) - Subtracts the second number from the first
   - **Multiply** (Cyan) - Multiplies two numbers
   - **Divide** (Orange) - Divides the first number by the second
3. The result appears in the result display section at the bottom
